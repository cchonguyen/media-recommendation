# Architecture Decision Records (ADRs)

- 2026-11-11: The web app on D1 is the only editing surface; Google Sheets is a one-way backup. Why: two-way Sheet diffing cannot survive sorts, deletes or mid-run edits.
- 2026-11-11: Stay on Workers Free. Every per-item loop is capped (intake 25, enrichment 10, grooming 15). Why: 50 outbound subrequests and 10 ms CPU per invocation.
- 2026-11-11: Intake idempotency lives in an `intake_log` table keyed by a SHA-256 of the normalised line, checked before Gemini and before insert or merge. Why: a hash on `media_items` cannot guard the merge path or lines that yield several items.
- 2026-11-11: Duplicates merge in two stages: title, type and year hint at intake; external ID after enrichment. Why: the canonical title does not exist at intake.
- 2026-11-11: Google Doc sweep and `POST /api/webhook/intake` share `ingestRawLines()`. Why: Gemini Web and Claude Web write to the Doc; iOS Shortcuts and Meta Muse post to the webhook.
- 2026-11-11: Google and Twitch tokens are cached in a D1 `system_kv` table. Why: Worker memory does not persist and signing costs CPU.
- 2026-11-11: IGDB is the only games source. Tavily and HowLongToBeat are dropped. Why: structured, deterministic data.
- 2026-11-11: The Doc clear uses `targetRevisionId` and keeps paragraph 1 as a header. Why: newer text survives a concurrent edit.
- 2026-11-11: UI is Hono with `hono/jsx` server-rendered HTML plus vanilla JS or HTMX. Why: no frontend build pipeline.
- 2026-11-11: `workers_dev = false` and `preview_urls = false`. Why: a `*.workers.dev` URL would bypass Cloudflare Access.
- 2026-11-11: Public share pages read from a strict column allowlist. Why: `personal_notes` and `review_text` must never leak.
- 2026-11-11: Slice 1 runs before Slice 0. Why: `main` carries the `harness-main-red` tag until a `package.json` with passing quick checks lands.
- 2026-11-11: Added `year_hint` to `media_items` and `CANONICAL_MERGE` to the activity event enum. Why: Stage 1 merge compares year hints, and Stage 2 merges need their own audit event.
- 2026-11-13: Adopt Harness UI (accent `azure`, density `comfortable`, plain voice), specified in `.spec/DESIGN_SPEC.md` as Slices 23.1 to 23.9. Why: one shared look across the owner's apps, and it fixes dark-mode contrast, `window.confirm`, the 9 second toast, duplicated CSS and phone touch targets.
- 2026-11-13: CSS is served inline from one TS module chain (`kit-css.generated.ts` built by `scripts/build-kit-css.mjs` from the synced `tokens.css` and `bundle.css`, plus `app-css.ts`, joined in `styles.ts`), not from an `/assets/app.css` route. A drift test fails when the generated file differs from `.harness/design-system/`. Why: `/*` sits behind Cloudflare Access and `/share/*` is a public bypass path configured outside the app, so a CSS route would break the share page or need a new bypass; inline CSS costs no subrequest and no per-request CPU, and the share CSP already allows `style-src 'unsafe-inline'`. Cost: about 20 KB of CSS on every HTML response (the share page is not cached beyond 60 seconds).
- 2026-11-13: Theme follows the device through `tokens.css` (`prefers-color-scheme`, dark default); no `data-theme` attribute and no theme script. Why: the kit already does this, and the share CSP forbids scripts.
- 2026-11-13: Web fonts (Newsreader, JetBrains Mono) load from Google Fonts on the private app only. `/share/:slug` keeps its exact CSP (`default-src 'none'`) and falls back to `ui-serif, Georgia` and `ui-monospace`. Why: `share.test.ts` asserts the CSP and the public page must stay free of third-party requests.
- 2026-11-13: Navigation has four destinations (Now & Next, Library, Completed Archive, Lists); the six media types become a pill sub-nav on Library pages. Why: the AppShell allows at most five destinations and the app had nine tabs.
- 2026-11-13: One `ui-btn--primary` per view, so Sweep Inbox Now and Backup are plain buttons; the primary is Add to Backlog, Create List or Save. Why: kit rule, and Start/Resume rows repeat many times.
- 2026-11-13: Archive keeps a confirming Dialog instead of an Undo toast; Delete list keeps a Dialog. Why: `POST /api/items/:id/status` can restore an Archived row only to Backlog, so a true Undo would change the item's status.
- 2026-11-13: Inline lucide SVG paths are hand-copied into `src/ui/icons.tsx`; no icon or UI JS library is added. Why: no frontend build pipeline and the Workers bundle stays small.
