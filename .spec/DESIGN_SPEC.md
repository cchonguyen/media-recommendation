# Design Spec: adopt Harness UI (Slices 23.1 to 23.9)

Status: written 2026-11-13 for Haiku `engineer` subagents. One slice per pull request, in order. No design judgment is needed: every class, string and file is named below. If something here is missing or contradicts the code, stop and ask. Do not improvise.

## 1. Goal

Move every screen (Now & Next, the six library tabs, Completed Archive, Lists, list editor, public `/share/:slug`) onto the Harness UI kit: tokens, `ui-` components, lucide inline SVG, kit Toast and Dialog. Fix these known gaps:

1. Dark-mode contrast. Today white text sits on `#7aa2ff` (about 2.5:1). The kit's `on-accent` ink fixes it with no hex in our code.
2. `window.confirm` (two calls in `src/ui/client.ts`) becomes the kit Dialog.
3. The 9 second `#toast` becomes the kit Toast (6 seconds, Undo only where a restore exists, errors that need a decision go in a Notice).
4. The duplicate CSS in `src/share/routes.tsx` is removed. One shared source feeds both surfaces.
5. Touch targets are 44 px below 640 px (kit classes do this; app classes below follow the same rule).
6. One shared AppShell (sidebar from 1100 px, bottom tab bar below).
7. Icons are lucide, inline SVG, no JS library.

## 3. Decisions (fixed)

| Topic | Decision |
| --- | --- |
| Accent | `data-accent="azure"` on `<html>` |
| Density | `data-density="comfortable"` on `<html>` |
| Theme | Dark first, follows the device. `tokens.css` already switches on `prefers-color-scheme` with dark as the default, so do NOT set `data-theme` and add no script. No `theme-lock`. |
| Display face | Newsreader through `--font-display` (kit default, restated once in `app.css`). Loaded from Google Fonts on the private app only. |
| Mono face | JetBrains Mono, same loading rule. |
| Fonts on `/share/:slug` | None loaded. The page CSP is `default-src 'none'; img-src https:; style-src 'unsafe-inline'; ...` and `share.test.ts` asserts it exactly. The stacks fall back to `ui-serif, Georgia` and `ui-monospace`. Do not change that CSP. |
| CSS source | One TS module chain: `kit-css.generated.ts` (tokens + bundle, generated by script, never hand-edited) + `app-css.ts` (app only) -> `styles.ts` exports `STYLES`. Both surfaces inline it as `<style>{raw(STYLES)}</style>`. No `/assets/app.css` route. Reason in ADR 2026-11-13: a route would be behind Cloudflare Access, which would break `/share/*` (public bypass configured outside the app), and the inline string costs no subrequest and no CPU after module load. |
| Load order | tokens, bundle, then app CSS. Inside `STYLES` that is the concatenation order. |
| Never edit | `.harness/design-system/tokens.css` and `bundle.css`. App tweaks go in `app-css.ts` only. |
| Voice | Plain. Existing Title Case button labels named in `SYSTEM_SPEC.md` 5.4 stay (Sweep Inbox Now, Backup to Google Sheets, Draft List with AI, Create List, Add to Backlog). New labels are sentence case. Never "OK" or "Submit". |
| Navigation | Four destinations: Now & Next, Library, Completed Archive, Lists. The six media types become a pill sub-nav on the Library pages. Reason: the kit allows at most five destinations, the app had nine tabs. |
| Primary button | One `ui-btn--primary` per view. Sweep, Backup, Start, Resume, Pause, row actions are plain `ui-btn`. Primary is only: Add to Backlog (home), Create List (lists), Save (list editor). Library pages have none. |
| Detail view | Dedicated route (`/lists/:id`), not master-detail. Recorded in the profile. |
| Reversible actions | Status moves act at once (as today). Archive keeps a confirming Dialog because the API can only restore an archived row to Backlog, so a true Undo would be wrong. Delete list is irreversible and keeps a Dialog. |

### 4.2 `src/ui/icons.tsx`

```tsx
import { raw } from "hono/html";
export type IconName = keyof typeof PATHS;
export function Icon(props: { name: IconName; size?: number }) // default size 16
```

Renders `<svg xmlns="http://www.w3.org/2000/svg" width={size} height={size} viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.75" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true">` then `{raw(PATHS[name])}`. These two hex values are copied from `tokens.css` (`--neon-azure`, `--on-accent` in dark) with a comment saying so. They are the only hex literals allowed in `.tsx` files, and only in `icons.tsx`.

### 4.3 `src/ui/controls.tsx`

```tsx
export function SelectBox(props: { id?: string; name?: string; label?: string; required?: boolean; attrs?: Record<string, string>; children?: Child })
// <div class="ui-select-wrap"><select class="ui-select" id name aria-label={label} required {...attrs}>{children}</select><Icon name="chevron-down" /></div>

export function Field(props: { id: string; label: string; help?: string; children?: Child })
// <div class="ui-field"><label class="ui-eyebrow" for={id}>{label}</label>{children}{help ? <span class="ui-help" id={`${id}-help`}>{help}</span> : null}</div>

export function Pill(props: { tone?: "mid" | "active" | "good" | "warn" | "bad"; icon?: IconName; children?: Child })
// <span class={tone ? `ui-pill ui-pill--${tone}` : "ui-pill"}>{icon ? <Icon name={icon} /> : null}{children}</span>

export function Missing(props: { text?: string })   // default "Not known yet"
// <span class="ui-missing">{text}</span>
```

Rules: a `Pill` with tone `good`, `warn` or `bad` must pass `icon` (state is never colour alone). `SelectBox` always wraps. Never write a bare `<select>`, `<input>`, `<textarea>` or `<button>` in a page after its slice (the 23.9 guard test enforces this).

### Slice 23.3: Kit Toast, Notice and Dialog in the client script `[UI / VISUAL]`

Target files: `src/ui/client.ts`, `src/ui/ui.test.ts`

Changes inside `CLIENT_SCRIPT` (keep it one IIFE, ES5 style, as today):

1. Constants near the top: `var ICON_ALERT`, `ICON_INFO`, `ICON_CHECK` as full `<svg ...>` strings (same attributes as `Icon`, size 16, from the icon table), used with `innerHTML` only on these static strings.
2. `toast(msg, opts)` replaces the old function. `opts` is `{ sticky?: boolean, actionLabel?: string, onAction?: function }`. It returns `{ close: function }`.
   - Container: `document.getElementById("toasts")`; if missing create `<div class="ui-toasts" id="toasts" aria-live="polite">` and append it to `document.body`.
   - Each toast: `<div class="ui-toast" role="status"><span class="ui-toast__msg"></span></div>`. Message set with `textContent`. If `actionLabel`, append `<button type="button" class="ui-toast__action">` that calls `onAction` then closes.
   - Timer 6000 ms unless `sticky`. Pause the timer on `mouseenter` and `focusin`, restart on `mouseleave` and `focusout`.
